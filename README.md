# FareRadar

FareRadar is a concept travel-metasearch landing page that showcases how an
online platform can surface the cheapest flight options and capture commission
on completed bookings. The project is a static site built with semantic HTML,
modern CSS and a sprinkle of vanilla JavaScript.

## Features

- Hero section with messaging for travelers and potential partners
- Search form that filters a sample dataset of flights loaded from JSON
- Dynamic fare cards with filters for airline, number of stops and sort order
- Mock booking and share interactions to demonstrate the on-site checkout flow
- Marketing content (features, partners, testimonials, FAQ) tailored to a travel
  audience

## Getting started

This project is framework-free. Use any static file server or open `index.html`
in your browser to explore the experience.

```bash
# using Python
python3 -m http.server 3000

# then open http://localhost:3000 in your browser
```

## Future enhancements

- Replace the static dataset with a real inventory source (airline APIs, GDS or
  affiliate feeds)
- Add authentication and a booking engine that integrates with partner systems
- Expose analytics dashboards for partners to review performance and payouts
